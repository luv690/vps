## 二、选购香港云服务器最容易踩的三个坑

我把市面上常见的翻车案例归纳一下，无非就是下面这几个，提前知道能少交不少学费。

### 坑一：搞不清BGP、CN2、CN2 GIA的区别

很多商家宣传页面会写"优化线路""BGP直连""CN2 GIA"，看着都挺唬人，实际差别挺大。

- **普通国际BGP**：走的是国际出口，回国延迟一般60到100ms，晚高峰容易波动。价格最便宜。
- **优质BGP（优化回国）**：通过多线BGP智能选路，电信走CN2、联通走自己的直连，平均延迟能压到50到70ms，性价比高。
- **CN2 GIA（精品网）**：电信最高等级的回国线路，延迟最低（30到50ms）、最稳定，但价格也最贵，而且只对电信用户优化明显。

野草云这边比较好的是同时提供"优质网"和"精品网"两种可选，独立服务器更是两条线都给（30M优质+15M精品），可以根据自己主要用的运营商和预算来选，这点比很多只给单一线路的商家厚道。

### 坑二：被"不限流量"忽悠

"不限流量"听起来很爽，但很多商家的不限流量是限制带宽的——比如5Mbps不限流量，看起来流量随便用，实际5Mbps的带宽跑大文件、跑视频也就是个摆设。反过来，"200M带宽+600G流量"这种组合虽然写着流量限制，但200M的带宽体验远比5M不限流量好得多。

判断的时候要看你自己的使用场景：建站、跑API、远程桌面这种持续中等带宽的需求，看带宽大小；做大文件传输、备份、爬数据这种突发高带宽的需求，看流量总额。两者别混。

### 坑三：只看价格不看商家稳定性

香港小机房这两年跑路的不少，便宜是真便宜，跑路也是真跑路。判断商家靠不靠谱，主要看三点：运营年限、是否有自主AS号和IP段、有没有实体公司主体。野草云（LucidaCloud Limited，香港公司注册编号2736053）从2012年做到现在13年了，自己持有APNIC和RIPE NCC的IP资源，这种持有自己IP段的商家跑路成本比租IP的二道贩子高得多，相对靠谱。
